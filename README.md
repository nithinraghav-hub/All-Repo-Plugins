# All-Repo-Plugins

A personal marketplace of Claude Code plugins.

## Installing

Add this repo as a plugin marketplace, then install a plugin from it:

```
/plugin marketplace add nithinraghav-hub/all-repo-plugins
/plugin install frontend-design
```

## Plugins

- **[frontend-design](plugins/frontend-design)** — Guidance for distinctive, intentional visual design when building new UI or reshaping an existing one. Sourced from [anthropics/claude-code](https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design).
