# ToyGenie brand assets

This repo holds ToyGenie brand assets (logos, mascot, favicon, prompt references).

Before any design, copy, content or code work for the ToyGenie Shopify store (www.toygenie.com.au),
read `docs/toygenie-shopify-theme-guide.md`. It captures the live theme's brand, tokens, page anatomy and
editing rules. If the live theme has changed since its snapshot date, refresh the guide from the store.
